# Postman

Импортировать soil_types.postman_collection.json. baseUrl по умолчанию — http://localhost:3000/api; для отдельного стенда изменить переменную. В Settings Postman указать Working directory = папка postman этого репозитория; файлы gravel.jpg и gravel.mp4 находятся рядом с коллекцией. При необходимости заново выбрать их в Body → form-data.

Коллекция содержит ровно 10 запросов. Для ленты включить id и next=true в том же запросе, не создавать одиннадцатый метод. Создание: name и файлы image/video, ответ только id. Публикация: description, looseningFactor, density. Идентификатор карточки сохраняется после создания; исходный seed содержит черновик пользователя 1, поэтому перед созданием его нужно опубликовать либо удалить.

ЛР3: текущий пользователь 1 фиксирован на сервере, вход и выход — заглушки.
