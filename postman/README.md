# Postman

Импортировать soil_types.postman_collection.json. baseUrl по умолчанию — http://localhost:3000/api; для отдельного стенда изменить переменную. В Settings Postman указать Working directory = папка postman этого репозитория; файлы gravel.jpg и gravel.mp4 находятся рядом с коллекцией. При необходимости заново выбрать их в Body → form-data.

Коллекция содержит ровно 10 запросов. Для ленты включить id и next=true в том же запросе, не создавать одиннадцатый метод. Создание: name и файлы image/video, ответ только id. Публикация: description, looseningFactor, density. Идентификатор карточки сохраняется после создания; при входе как user1 сначала опубликовать или удалить исходный черновик id=6; для user3 подготовка не требуется.

ЛР4: сначала выполнить вход user3/pass3 (у него нет исходного черновика). Скрипт запроса сохраняет sessionId в переменной коллекции; Cookie Jar отключён. Заголовок Cookie содержит sessionId={{sessionId}}. Для проверки гостя снять галочку у заголовка, для создателя включить. Не сохранять реальную сессию в коммите.
