## Как реализовано

### 1) Три страницы

`Лента` — вертикальное видео на весь экран, поверх него название грунта, поля
по предметной области, описание с раскрытием и кнопка перехода к следующему.
`Добавление` — форма с полями черновика. `Каталог` — карточки в две колонки с
фильтром. Внизу всех страниц панель вкладок.

### 2) Коллекция без базы данных

Семь типов грунтов лежат в массиве в `src/soils/soils.data.ts`. У каждого
статус `published`, `draft` или `deleted`: пять опубликованных, глина в
черновике, лёсс удалён. Удалённые не отображаются нигде, черновик — только на
странице добавления.

### 3) Три GET-запроса

```
GET /soils?maxLoosening=1.2   каталог с фильтрацией
GET /soils/feed/:id?next=true  лента, с параметром — следующий грунт
GET /soils/draft               страница добавления
```

### 4) Фильтрация на сервере

Форма отправляется методом GET, контроллер отсеивает коллекцию и отдаёт
браузеру только подходящие карточки. Введённое значение возвращается в поле:

```ts
const limit = maxLoosening ? Number(maxLoosening.replace(',', '.')) : undefined;
```

### 5) Изображения и видео из MinIO

В коллекции хранятся только имена файлов, шаблон склеивает адрес:

```hbs
<img src="{{../mediaUrl}}/{{this.imageName}}">
```

Браузер забирает файлы напрямую из хранилища по адресу
`http://localhost:9000/soils/sand.jpg`, минуя сервер приложения.

### 6) Раскрытие описания без JavaScript

Использован тег `<details>` — он умеет раскрываться сам:

```hbs
<details class="feed-details">
  <summary>Подробнее</summary>
  <p class="feed-full">{{soil.fullDescription}}</p>
</details>
```

1. Разработать дизайн трёх страниц в Figma по стилистике сайта-референса.

## Задание

Создание дизайна приложения в Figma, базовая шаблонизация для услуг,
развёртывание MinIO. Требуется разработать дизайн трёх страниц, повторив
стилистику существующего ресурса по теме, и создать базовый интерфейс из трёх
страниц в портретном режиме: лента с автоматически проигрывающимся видео,
страница добавления и плитка карточек. Всего три GET-запроса и одна
коллекция, данные берутся из массива без использования базы данных.
Изображения и видео хранятся в MinIO. Без JavaScript.
